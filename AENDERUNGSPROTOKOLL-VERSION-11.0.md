# Version 11.0.0 – Foto-Workflow Grundsystem

- Öffentlicher Bereich „Fotos hochladen“ vereinfacht; die bisherige separate Schülergalerie wurde entfernt.
- Neuer Adminbereich „Fotoeingang“ mit Statusübersicht, Filtern und vorbereitetem Kartenlayout.
- Neue Datenstruktur `content/photo-inbox.json` für künftige Forms-/SharePoint-Einreichungen.
- Direkter Zugang zum Fotoeingang im Admin-Dashboard.
- Grundlage für Microsoft Graph in Version 11.1.

Hinweis: In Version 11.0 werden noch keine echten Microsoft-Forms-Daten geladen.
