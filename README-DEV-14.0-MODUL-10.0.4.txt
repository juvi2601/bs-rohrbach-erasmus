DEV 14.0 – Modul 10.0.4 Deutsche Rollen im CSV-Import

CSV-Rollen können jetzt benutzerfreundlich auf Deutsch angegeben werden:
- Admin / Administrator / Administratorin -> Admin
- Lehrkraft / Lehrer / Lehrerin / Reiseleitung / Reiseredaktion -> Lehrkraft/Reise-Redaktion
- Schüler / Schülerin / Schueler / Schuelerin -> Schüler*in

Die bisherigen technischen Begriffe admin, teacher und student bleiben kompatibel.
Ohne Rollenangabe wird weiterhin Schüler*in verwendet.

Beispiel:
E-Mail;Name;Rolle
max.mustermann@bs-rohrbach.ac.at;Max Mustermann;Schüler
eva.beispiel@bs-rohrbach.ac.at;Eva Beispiel;Lehrkraft

Sonst keine funktionalen Änderungen.
