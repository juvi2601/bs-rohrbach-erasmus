Neu:
- /admin/hilfe.html?trip=<reise>
- Zugriff nur für Admin und Lehrkraft/Reise-Redaktion der jeweiligen Reise.
- Schüler*innen und nicht berechtigte Konten erhalten serverseitig 403.
- Lehrkräfte sehen die Unterwegs-Anleitungen: Medien, Tagebuch, Live-Status, Galerie.
- Admin sieht zusätzlich die ausführliche Anleitung für neue Reisen, Teilnehmer/Rollen und Veröffentlichung.
- Links werden reisebezogen weitergegeben.

Wichtig:
- Kein öffentlicher Hilfe-Menüpunkt.
- Öffentliche Reisewebsite bleibt unverändert.
- Öffentliche Footer-Version bleibt bewusst unverändert bis zum finalen STABLE-Abgleich.
