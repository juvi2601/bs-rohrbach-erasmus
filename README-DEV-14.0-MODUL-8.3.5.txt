DEV 14.0 – Modul 8.3.5 Master-Template Feinschliff

- Dunkle Website-Flächen werden aus der gewählten Hauptfarbe abgeleitet.
- Footer und „Interner Bereich“-Navigation verwenden die dunkle Reisevariante.
- Geschützte Vorschau-Leiste verwendet ebenfalls die dunkle Reisevariante.
- Kartenorte benötigen kein Bild: ohne Bild wird ein sauberer Platzhalter dargestellt.
- Kein kaputtes Bildsymbol mehr in Kartenliste oder Kartendetail.
- favicon.ico wird explizit als image/x-icon und inline ausgeliefert.
- PNG-Favicons / Apple Touch Icon erhalten korrekte PNG-Header.
- Brüssel-2026-Inhaltsdaten bleiben unverändert.
