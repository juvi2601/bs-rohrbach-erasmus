DEV 14.0 – Modul 8.3.6 Dynamisches Theme & Kartenfix

- Haupt-/Akzentfarben greifen jetzt konsequent auf Buttons und aktive Bedienelemente.
- Interner-Bereich-Button verwendet die Reise-Hauptfarbe; kein separater Unterstrich.
- Reisephase/Progress, Tages-Cover und Footer verwenden eine dunkle Variante der Reise-Hauptfarbe.
- Karten-Tile-Layer auf HTTPS OpenStreetMap Standardtiles umgestellt.
- Kartenansicht ist nicht mehr auf Brüssel-Bounds fest verdrahtet.
- Karten-Umschalter zeigt dynamisch das Reiseziel statt „Brüssel“.
- Countdown-Datum wird deutsch formatiert, wenn ein ISO-Datum geliefert wird.
- Kartenorte ohne Bild behalten den sauberen Platzhalter aus 8.3.5.
- Favicon-Fix aus 8.3.5 bleibt erhalten.

Hinweis: Automatische Geokodierung/Hotel-Übernahme wird als separater, gezielt testbarer Schritt ergänzt.
