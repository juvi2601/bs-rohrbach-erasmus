DEV 15.0.4 – Verwaltbares Lehrkräfte-Handbuch

- Lehrkräfte öffnen das aktuelle PDF direkt aus der Reise-Redaktion.
- Hilfe & Tutorials enthält ebenfalls einen PDF-Link.
- Admins erhalten „Handbuch verwalten“ mit PDF-Upload.
- Nur Admins dürfen eine neue Version hochladen.
- Zulässig: gültige PDF bis 25 MB.
- Vorherige hochgeladene Version wird automatisch als R2-Backup gespeichert.
- Die aktuelle Benutzer-PDF ist als Startversion eingebaut.
- Nach dem ersten Admin-Upload verwenden alle Reisen automatisch die neue R2-Version.
