DEV 15.0.7 – Reise-Status & Archiv

Neu:
- Lebenszyklus pro Reise: Entwurf → Veröffentlicht → Offline / Archiviert.
- Veröffentlicht: erscheint unter „Aktuelle & veröffentlichte Reisen“ und ist öffentlich erreichbar.
- Offline: verschwindet aus der öffentlichen Übersicht und die Reise-URL liefert keine öffentliche Website mehr. Daten bleiben vollständig erhalten.
- Archiviert: bleibt öffentlich erreichbar, erscheint aber im eigenen Bereich „Vergangene Reisen / Archiv“.
- Admin kann veröffentlichte Reisen offline nehmen oder archivieren.
- Offline- und archivierte Reisen können wieder veröffentlicht werden.
- Archivierte Reisen können auch vollständig offline genommen werden.
- Die bestehende Testreise wird anhand ihres echten Veröffentlichungsstatus eingeordnet; der bloße Entwurfsdatensatz entscheidet nicht mehr über die öffentliche Sichtbarkeit.
