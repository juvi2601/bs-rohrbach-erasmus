# Update 11.2.0 – auswählbare Programmsymbole

## Enthaltene Dateien

- `public/app.js`
- `public/admin/config.yml`
- `admin/config.yml`

## Installation über GitHub Desktop

1. ZIP entpacken.
2. Den Inhalt des Ordners `Update-11.2.0` in den lokalen Repository-Ordner `bs-rohrbach-erasmus` kopieren.
3. Vorhandene Dateien ersetzen lassen.
4. In GitHub Desktop die drei geänderten Dateien kontrollieren.
5. Commit-Nachricht: `Version 11.2.0 – Programmsymbole im CMS`
6. **Commit to main** und danach **Push origin**.

## Funktion

Bei jedem Programmpunkt gibt es im CMS nun das Feld **Programmsymbol**. Die manuelle Auswahl hat Vorrang. Bei **Automatisch erkennen** oder bei alten Einträgen ohne Symbol bleibt die bisherige automatische Erkennung aktiv.

Bestehende Programmdaten werden nicht verändert.
