BS Rohrbach Erasmus+ – Version 13.9 – Schüler*innenliste & CSV

Neu:
- Schüler*innenzugriff wird reisebezogen in Cloudflare R2 gespeichert
- Admin kann unter „Benutzer & Rollen“ eine CSV-Datei importieren
- akzeptiert Schul-E-Mail-Adressen @bs-rohrbach.ac.at
- Semikolon, Komma und Tabulator werden unterstützt
- Import ersetzt die aktuelle Schüler*innenliste; einzelne Einträge können entfernt werden
- Rolle Schüler*in erhält ausschließlich media.upload
- Foto-/Video-Upload ist ab jetzt auf Admin, Lehrkräfte und freigeschaltete Schüler*innen beschränkt
- andere Microsoft-Konten der BS Rohrbach erhalten keinen Upload-Zugriff
- Admin-/Lehrkraftrollen können durch CSV nicht überschrieben werden
- spätere CSV-Änderungen wirken sofort, ohne GitHub-Commit oder Deployment

Beim ersten Einsatz ist die Schüler*innenliste leer. Bis zum Import können nur Admin und Lehrkräfte hochladen.
